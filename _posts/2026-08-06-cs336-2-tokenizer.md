## Preliminary

### `merge_ranks`

This records a ranking for each merging pair. We know the `merges` is like:

```json
[
  ["20", "74"], 
  ["68", "65"], 
  ["20", "61"], 
  ["20", "73"], 
  ...
]
```

And we map each pair to a ranking, which has smaller number i.e. higher priority if its corresponding pair shows earlier.

```python
self.merge_ranks = {pair: rank for rank, pair in enumerate(self.merges)}
```

The code adopts the strategy of "selecting the merge pair with the highest priority (minimum index) each time". This is consistent with the BPE standard algorithm (which always merges the pairs with the highest frequency during training): the higher the frequency of the pairs during training, the higher their rank value in the merge list. Priority is given to trained merging pairs that were merged earlier during encoding, ensuring that the encoding results are consistent with the logic of constructing the vocabulary during training.

### `load_vocab_merges`

`fromhex()` reads hexadecimal number strings and converts them to bytes.

```python
def load_vocab_merges(
    vocab_path: str,
    merges_path: str
) -> tuple[dict[int, bytes], list[tuple[bytes, bytes]]]:
    with open(vocab_path, encoding="utf-8") as f:
        raw_vocab = json.load(f)
    with open(merges_path, encoding="utf-8") as f:
        raw_merges = json.load(f)

    vocab = {int(token_id): bytes.fromhex(token) for token_id, token in raw_vocab.items()}
    merges = [(bytes.fromhex(left), bytes.fromhex(right)) for left, right in raw_merges]
    return vocab, merges
```

### `_encode_chunk`

This part will take an example. Suppose that we have initialized the `vocab` and the `merges`, then we input `"hello world<|endoftext|>"`. The function `def encode(self, text: str) -> list[int]:` will first split the input sequence by special tokens and `"hello world"` will be processed by `def _encode_chunk(self, text: str) -> list[int]:`. The function is like:

```python
def _encode_chunk(self, text: str) -> list[int]:
    ids: list[int] = []
    for match in PAT.finditer(text):
        token_bytes = match.group().encode("utf-8")
        pieces = [BYTE_TOKENS[byte] for byte in token_bytes]

        while len(pieces) > 1:
            best_index = -1
            best_rank = float("inf")
            for i, pair in enumerate(zip(pieces, pieces[1:])):
                rank = self.merge_ranks.get(pair)
                if rank is not None and rank < best_rank:
                    best_index = i
                    best_rank = rank

            if best_index == -1:
                break

            pieces[best_index : best_index + 2] = [pieces[best_index] + pieces[best_index + 1]]

        ids.extend(self.token_to_id[piece] for piece in pieces)
    return ids
```

The `vocab` and `merges` can be in this example:

```python
vocab = {0: b'h', 1: b'e', 2: b'l', 3: b'o', 4: b' ', 5: b'w', 6: b'r', 7: b'd', 8: b'he', 9: b'll', 10: b'o ', 11: b'wo', 12: b'or', 13: b'ld', 14: b'hell', 15: b'world'}

merges = [
    (b'h', b'e'),      # rank 0 → "he"
    (b'l', b'l'),      # rank 1 → "ll"
    (b'o', b' '),      # rank 2 → "o "
    (b'w', b'o'),      # rank 3 → "wo"
    (b'o', b'r'),      # rank 4 → "or"
    (b'l', b'd'),      # rank 5 → "ld"
    (b'he', b'll'),    # rank 6 → "hell"
    (b'wo', b'r'),     # rank 7 → "wor"
    (b'wor', b'ld'),   # rank 8 → "world"
]
```

The chunk `"hello world"` will be processed:

1. The regular expression `PAT` will cut this chunk into several blocks and treat them one by one. After `PAT`, we have `"hello"` and `" world"`. Now we treat `"hello"`.
    ```python
    for match in PAT.finditer(text):
    ```
2. Encode the block into UTF-8 byte string, and divide it into single bytes in a list. The process is: `"hello"` -> `b"hello"` -> `[b'h', b'e', b'l', b'l', b'o']`.
    ```python
    token_bytes = match.group().encode("utf-8")
    pieces = [BYTE_TOKENS[byte] for byte in token_bytes]
    ```
3. Enter the loop: search for all adjacent pairs in `pieces` and find the pair with the highest priority (i.e. the lowest rank) in the `merge_ranks`. Because the key of `merge_ranks` is the merge pair and the value is its index, the smaller the index, the earlier it is merged during training, and the higher the priority.
4. If a combinable pair (`best_index != -1`) is found, the two elements of the pair are merged into a new byte, replacing the original position.
5. Repeat steps 3-4 until there are no merges available (all adjacent pairs are not in the `merge_ranks`).
6. Finally, convert each byte in the final `pieces` into an ID and append it to the result list.

This example:

* **input**: `"hello world<|endoftext|>"`
* **after splitting by special tokens**: `"hello world"`
* **after PAT**: `"hello"` and `" world"`
* `"hello"`
  * `b"hello"`
  * **`pieces`**: `[b'h', b'e', b'l', b'l', b'o']`
  * **`merges` (b'h', b'e')**: `[b'he', b'l', b'l', b'o']`
  * **`merges` (b'l', b'l')**: `[b'he', b'll', b'o']`
  * **`merges` (b'he', b'll')**: `[b'hell', b'o']`
  * **`ids`**: `[14, 3]`
* `" world"`
  * `b" world"`
  * **`pieces`**: `[b' ', b'w', b'o', b'r', b'l', b'd']`
  * **`merges` (b'w', b'o')**: `[b' ', b'wo', b'r', b'l', b'd']`
  * **`merges` (b'l', b'd')**: `[b' ', b'wo', b'r', b'ld']`
  * **`merges` (b'wo', b'r')**: `[b' ', b'wor', b'ld']`
  * **`merges` (b'wor', b'ld')**: `[b' ', b'world']`
  * **`ids`**: `[14, 3, 4, 15]`
* **output**: `[14, 3, 4, 15, 16]`
