BPE (Byte-Pair Encoding) is a compression algorithm that iteratively replaces ("merges") the most frequent pair of bytes with a single, new unused index. Note that this algorithm adds subword tokens to our vocabulary to maximize the compression of our input sequences—if a word occurs in our input text enough times, it'll be represented as a single subword unit.

## Preliminary

### Some history

1. **word-level tokenizers**: really big vocabulary, out-of-vocabulary issue.
2. **byte-level tokenizers**: only has 256 elements in vocabulary, but very long output sequence.
3. **BPE**: a compromise.


### Three core functions

1. `def find_chunk_boundaries(file: BinaryIO, desired_num_chunks: int, split_special_token: bytes) -> list[int]:` Divide a large file into multiple blocks, ensuring that the boundary of each block falls after a specified special token (so that the special token is not split). 将一个大文件划分为多个块，每个块的边界必须落在指定的特殊 token 之后（这样特殊 token 不会被切分）。
2. `def pretokenize(file_path: str | os.PathLike, special_tokens: list[str]) -> Counter[tuple[bytes, ...]]:` Read the entire file (possibly in chunks) and count the frequency of all words. 读取整个文件（可能分块），统计所有词的频次。
3. `def train_bpe(input_path: str, vocab_size: int, special_tokens: list[str]) -> tuple[dict[int, bytes], list[tuple[bytes, bytes]]]:` The main process.

### Pipeline

1. **Vocabulary initialization**: Initialize the vocabulary to consist of 256 bytes plus a special token (with an ID assigned first). 初始化词汇表为 256 个字节 + 特殊 token（先分配 ID）。
2. **Pre-tokenization**: Read the file, use GPT-2 regular expression PAT to perform tokenization, and skip special tokens. 预分词：读取文件，使用 GPT‑2 正则表达式 PAT 切分，跳过特殊 token。
3. **Pair frequency**: Count the frequency of adjacent byte pairs (within the same chunk only), and maintain a dictionary where each pair is mapped to its corresponding frequency. 统计相邻字节对频次（仅限同一词块内），并维护一对->频次字典。
4. **Iterative merging**
5. **Return vocab and merges**


### An example

```text
low low low low low
lower lower widest widest widest
newest newest newest newest newest newest
```


### Core data structures

* `PAT= regex.compile(r"""'(?:[sdmt]|ll|ve|re)| ?\p{L}+| ?\p{N}+| ?[^\s\p{L}\p{N}]+|\s+(?!\S)|\s+""")`: Magic that GPT-2 used to pre-tokenize.
* `word_counts`: A counter records the pre-tokenized word counts. In this example:
  ```python
  {
      (b'l', b'o', b'w'): 5,
      (b' ',): 13,
      (b'\n',): 2,
      (b'l', b'o', b'w', b'e', b'r'): 2,
      (b'w', b'i', b'd', b'e', b's', b't'): 3,
      (b'n', b'e', b'w', b'e', b's', b't'): 6
  }
  ```
* `pair_counts`: A counter records each neighbour pair byte frequency. In this example:
  ```text
  (l, o): 7
  (o, w): 7
  (w, e): 8   (来自 lower 的 2 + newest 的 6)
  (e, r): 2
  (w, i): 3
  (i, d): 3
  (d, e): 3
  (e, s): 9   (来自 widest 的 3 + newest 的 6)
  (s, t): 9   (来自 widest 的 3 + newest 的 6)
  (n, e): 6
  (e, w): 6
  ```
* `pair_to_words: defaultdict[tuple[bytes, bytes], set[tuple[bytes, ...]]]`: A map of each byte pair to its corresponding word.
* `vocab = {i: bytes([i]) for i in range(256)}`: The initial vocabulary with 256 bytes, later will be added special tokens and merged pairs.
* `merges: list[tuple[bytes, bytes]]`: Merges computed.

### `find_chunk_boundaries`

Receives 3 parameters:

```python
def find_chunk_boundaries(
    file: BinaryIO,
    desired_num_chunks: int,
    split_special_token: bytes,
) -> list[int]:
```

1. Get total file size in bytes.
2. Initial guesses for chunk boundary locations, uniformly spaced.
3. Read ahead by 4k bytes at a time.
  * If EOF, this boundary should be at the end of the file.
  * Else, find the special token in the mini chunk.
4. Make sure all boundaries are unique, but might be fewer than desired_num_chunks.


### `pretokenize`

Small file text is all processed in one chunk. Big file splits text into several chunks with a constant byte size, each chunk is not processed in parellel, because I haven't implemented it.

```python
def pretokenize(
    file_path: str | os.PathLike,
    special_tokens: list[str],
) -> Counter[tuple[bytes, ...]]:
    
    valid_special_tokens = [token for token in special_tokens if token]
    file_size = os.path.getsize(file_path)
    if file_size <= PRETOKENIZE_CHUNK_SIZE_BYTES or not valid_special_tokens:
        with open(file_path, encoding="utf-8") as f:
            return _count_pretokens_in_text(f.read(), special_tokens)
    
    desired_num_chunks = max(1, (file_size + PRETOKENIZE_CHUNK_SIZE_BYTES - 1) // PRETOKENIZE_CHUNK_SIZE_BYTES)
    split_special_token = valid_special_tokens[0].encode("utf-8")
    word_counts: Counter[tuple[bytes, ...]] = Counter()
    
    with open(file_path, "rb") as f:
        boundaries = find_chunk_boundaries(f, desired_num_chunks, split_special_token)
        for start, end in zip(boundaries, boundaries[1:]):
            f.seek(start)
            text = f.read(end - start).decode("utf-8", errors="ignore")
            text = text.replace("\r\n", "\n")
            word_counts.update(_count_pretokens_in_text(text, special_tokens))
    
    return word_counts
```

The function called to count pre-tokens in the chunk first joins the special tokens together using `|`:

```python
special_pattern = "|".join(regex.escape(token) for token in valid_special_tokens)
```

Then the regular expression will split the chunk text by each special token, thus we now have text splits without any special tokens:

```python
parts = regex.split(special_pattern, text)
```

### `train_bpe`

Follow 5 steps:

1. vocabulary initialization
2. pretokenization
3. pair frequency
4. merges
5. return

```python
def train_bpe(
    input_path: str,
    vocab_size: int,
    special_tokens: list[str],
) -> tuple[dict[int, bytes], list[tuple[bytes, bytes]]]:
    
    # step1 vocabulary initialization
    vocab = {i: bytes([i]) for i in range(256)}
    
    for token in special_tokens:
        vocab[len(vocab)] = token.encode("utf-8")
    
    # step2 pretokenization
    word_counts = pretokenize(input_path, special_tokens)
    
    # step3 pair frequency
    pair_counts: Counter[tuple[bytes, bytes]] = Counter()
    pair_to_words: defaultdict[tuple[bytes, bytes], set[tuple[bytes, ...]]] = defaultdict(set)
    for word, count in word_counts.items():
        _add_word_pairs(word, count, pair_counts, pair_to_words)

    # step4 merges
    merges: list[tuple[bytes, bytes]] = []
    while len(vocab) < vocab_size and pair_counts:
        best_pair = max(pair_counts, key=lambda pair: (pair_counts[pair], pair))
        merged_token = best_pair[0] + best_pair[1]

        merges.append(best_pair)
        vocab[len(vocab)] = merged_token

        affected_words = list(pair_to_words.get(best_pair, ()))
        for old_word in affected_words:
            count = word_counts.pop(old_word, 0)
            if count == 0:
                continue

            _remove_word_pairs(old_word, count, pair_counts, pair_to_words)
            new_word = _merge_word(old_word, best_pair, merged_token)
            word_counts[new_word] += count
            _add_word_pairs(new_word, count, pair_counts, pair_to_words)
    
    return vocab, merges
```

3 key helper functions:

1. `_add_word_pairs`: Add byte pairs in a word to `pair_counts` and `pair_to_words`.
  ```python
  def _add_word_pairs(
      word: tuple[bytes, ...],
      count: int,
      pair_counts: Counter[tuple[bytes, bytes]],
      pair_to_words: defaultdict[tuple[bytes, bytes], set[tuple[bytes, ...]]],
  ) -> None:
    for pair in zip(word, word[1:]):
        pair_counts[pair] += count
        pair_to_words[pair].add(word)
  ```
2. `_remove_word_pairs`: Remove all byte pairs in a word from `pair_counts` and `pair_to_words`.
  ```python
  def _remove_word_pairs(
      word: tuple[bytes, ...],
      count: int,
      pair_counts: Counter[tuple[bytes, bytes]],
      pair_to_words: defaultdict[tuple[bytes, bytes], set[tuple[bytes, ...]]],
  ) -> None:
      for pair in zip(word, word[1:]):
          pair_counts[pair] -= count
          if pair_counts[pair] <= 0:
              del pair_counts[pair]

          words = pair_to_words.get(pair)
          if words is not None:
              words.discard(word)
              if not words:
                  del pair_to_words[pair]
  ```
3. `_merge_word`: Generate a new word with specific pairs merged, e.g., old word: `(b'h', b'e', b'l', b'l', b'o')`, merge pair `(b'l', b'l')`, new word: `(b'h', b'e', b'll', b'o')`.
```python
def _merge_word(
    word: tuple[bytes, ...],
    pair_to_merge: tuple[bytes, bytes],
    merged_token: bytes,
) -> tuple[bytes, ...]:
    first, second = pair_to_merge
    merged_word: list[bytes] = []
    i = 0
    while i < len(word):
        if i + 1 < len(word) and word[i] == first and word[i + 1] == second:
            merged_word.append(merged_token)
            i += 2
        else:
            merged_word.append(word[i])
            i += 1
    return tuple(merged_word)
```

**What did we do in the final part of merging?**

1. Select the best pair with the highest frequency and in the biggest lexicographical order:
  ```python
  best_pair = max(pair_counts, key=lambda pair: (pair_counts[pair], pair))
  ```
2. Add the best pair to `vocab` and `merges`:
  ```python
  merges.append(best_pair)
  vocab[len(vocab)] = merged_token
  ```
3. Eliminate old word influence. First we need to delete the old word from `word_counts`, `pair_counts` and `pair_to_words`. Then we merge and generate a new word. Finally we add the new word to `word_counts`, `pair_counts` and `pair_to_words`.
